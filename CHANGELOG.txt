v0.4.12 - Guild Connection Polish
--------------------------------------------------------------------------------
[ADDED] Guild members with any delegated rank permission display the Officer1 chat icon; Guild Masters retain the GM icon
[FIX] Missing or stale addon responses no longer trigger verification warnings when no active guild rule requires an addon response
[ADDED] Test admins can show rolling incoming and outgoing iRC traffic bytes per minute on the Testing page
[ADDED] Test admins can optionally profile selected iRC function hotspots over a rolling minute without changing global WoW profiling settings
[CHANGED] Testing metrics now show the top five packet types by bytes and top five profiled functions by elapsed time
[CHANGED] Grouped and alphabetized English localization keys by feature for easier editing; text and placeholders are unchanged
[FIX] RP Talk leaves item and other chat hyperlinks untouched while still transforming ordinary text around them
[CHANGED] Localization now loads from Localization/locale.xml and enUS.lua, matching iWR's folder structure; chat announcements and icon tooltips use localization keys
[FIX] Chat notices, warnings, and whisper entry points omit the realm suffix for same-realm characters while preserving full names for addon sync
[ADDED] Right-click Guild Map pins for Whisper and Invite actions
[CHANGED] Guild Map pin menu now fits its labels with a smaller, tighter layout
[FIX] Guild Members right-click menu now draws above roster rows
[FIX] Clicking outside the profession search field clears typing focus without resetting its filter
[FIX] Chat-icon hover tooltips no longer capture mouse input or add a frame-wide mouse-leave hook to the chat window, preserving click-through outside links
